    1. Mental Model du Relais Cloud

    La PWA sauvegarde chaque fait localement dans le localStorage. Google Sheets et Apps Script servent de tampon Cloud gratuit pour réceptionner les synchros quand le réseau est disponible, avant le rapatriement ultérieur vers le Raspberry Pi.

    2. La règle absolue : Navigation Privée

    Piège multi-comptes : Google gère mal les sessions multiples connectées en même temps. Ouvre systématiquement la feuille et l'éditeur Apps Script en navigation privée avec le compte Google dédié au projet.

    3. Procédure de déploiement d'une version

    Pour modifier le script sans casser l'URL Web de la PWA :

    1. Ajuster le code dans Apps Script et cliquer sur l'icône de disquette (Enregistrer).

    2. Cliquer sur Déployer > Gérer les déploiements.

    3. Cliquer sur le Crayon (Modifier) à côté du déploiement actif.

    4. Dans le menu Version, sélectionner impérativement « Nouvelle version ».

    5. Cliquer sur Déployer. L'adresse se terminant par /exec reste identique.

    1. Structure du tableur Google Sheets (8 colonnes)

    Sur la ligne 1 de la feuille active, définir rigoureusement :

    id | timestamp_utc | date_fr | domaine | action | valeur | unite | reception_utc

    2. Code Apps Script récepteur (Code.gs)

    function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    var items = Array.isArray(data) ? data : [data];
    var receptionTime = new Date().toISOString();
    
    items.forEach(function(item) {
      sheet.appendRow([
        item.id,
        item.timestamp,
        item.date_fr || '',
        item.domain || 'general',
        item.action || 'passage',
        item.value !== null ? item.value : '',
        item.unit || '',
        receptionTime
      ]);
    });
    
    return ContentService.createTextOutput(JSON.stringify({
      status: "success",
      count: items.length
    })).setMimeType(ContentService.MimeType.JSON);
  } catch (error) {
    return ContentService.createTextOutput(JSON.stringify({
      status: "error",
      message: error.toString()
    })).setMimeType(ContentService.MimeType.JSON);
  }
}
